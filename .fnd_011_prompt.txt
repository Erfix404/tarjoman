## Required Actions
1. Implement Structured Logging & Redaction Engine in `src/tarjoman/core/logging.py`:
   - **Secret Redaction Layer**:
     - `RedactionFilter(logging.Filter)` and `redact_secrets(val: Any) -> Any`:
       - Intercepts all log records (`record.msg`, `record.args`, `record.exc_info`, and any `extra` fields).
       - Regex patterns for API keys and tokens:
         - Standard OpenAI/Anthropic/generic key patterns (e.g. `sk-[a-zA-Z0-9_-]{20,}`, `ant-[a-zA-Z0-9_-]{20,}`).
         - Bearer tokens (`Bearer\s+[a-zA-Z0-9._~+/-]+=*`).
         - Authorization / API key headers (`(?:Authorization|api[_-]?key|x-api-key|secret|token)\s*[:=]\s*['"]?[^\s'",;]+`).
         - URL query parameter tokens (`[?&](?:api[_-]?key|key|token|secret)=[^&\s]+`).
       - Replaces secrets with `[REDACTED]`.
       - Handles nested structures (dict, list, tuple, exceptions, stack traces).
   - **JSON Log Formatter (`JSONFormatter(logging.Formatter)`)**:
     - Produces single-line JSON objects with keys:
       - `timestamp`: ISO-8601 UTC timestamp.
       - `level`: Log level name (INFO, WARNING, ERROR, DEBUG, etc.).
       - `logger`: Logger name (e.g. `tarjoman.core`, `tarjoman.pipeline`).
       - `message`: Sanitized log message.
       - `correlation_id`: Active correlation ID from contextvars (or None).
       - `operation_id`: Active operation ID from contextvars (or None).
       - `job_id`: Active job ID from contextvars (or None).
       - `project_id`: Active project ID from contextvars (or None).
       - `provenance`: Active provenance metadata dict if attached.
       - `exception`: Sanitized exception details / stack trace if `exc_info` is present.
       - `extra`: Additional sanitized custom fields.
   - **Plain Text Formatter (`TextFormatter(logging.Formatter)`)**:
     - Human-readable format with timestamps and redaction for CLI/interactive dev use.
   - **Context Tracking (`ProvenanceContext` / ContextVars)**:
     - `set_correlation_id(id: str)`, `get_correlation_id() -> Optional[str]`
     - `set_operation_context(operation_id: Optional[str] = None, job_id: Optional[str] = None, project_id: Optional[str] = None, metadata: Optional[Dict[str, Any]] = None)`
     - `bind_provenance(**kwargs)` context manager to scope operation/job IDs and provenance cleanly to async tasks and threads.
     - `get_provenance_context() -> Dict[str, Any]`
   - **Configuration Function (`configure_logging`)**:
     - `configure_logging(level="INFO", format="json"|"text", stream=None, handler=None)`
     - Reads environment variables `TARJOMAN_LOG_FORMAT` ("json" or "text") and `TARJOMAN_LOG_LEVEL` if not explicitly passed.
     - Attaches `RedactionFilter` to all handlers by default.
   - **Provider Error Sanitizer (`sanitize_provider_error`)**:
     - Helper to wrap or sanitize raw HTTP/SDK provider errors (e.g. 401 Unauthorized containing raw auth header or API key), stripping any credential before logging or raising.
