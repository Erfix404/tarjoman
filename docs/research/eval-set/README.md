# مجموعه ارزیابی کوچک فارسی (پیش‌نویس)

این مجموعه برای سنجش دو چیز نوشته شده: **دقت** (وفاداری به متن مبدأ) و **روانی** (طبیعی بودن فارسی). این دو امتیاز جدا گزارش می‌شوند، نه یک عدد واحد.

## فایل‌ها

- `samples.jsonl`: هر خط یک نمونه با متن انگلیسی، ترجمه‌ی تحت‌اللفظی و ترجمه‌ی طبیعی.

## ساختار هر نمونه

| فیلد | معنا |
|---|---|
| `id` | شناسه‌ی یکتا |
| `genre` | ژانر (`dialogue`, `narrative`, `technical`, `news`) |
| `source` | متن انگلیسی |
| `literal` | نمونه‌ی ترجمه‌نمایی برای سنجش؛ عمداً حاوی خطای شناخته‌شده |
| `natural` | ترجمه‌ی طبیعی پیشنهادی؛ هنوز توسط گویشور بومی بازبینی نشده |
| `calques` | الگوهای ترجمه‌نمایی موجود در `literal` |

## روش استفاده

1. به یک داور (LLM یا بازبین انسانی) `source` و یک ترجمه‌ی ناشناس بدهید.
2. داور دو امتیاز ۱ تا ۵ بدهد: **دقت** و **روانی**.
3. داور الگوهای ترجمه‌نمایی را علامت بزند. نسبت جمله‌های علامت‌خورده گزارش شود.
4. نتیجه را روی صفحه‌ی دو‌بعدی (دقت، روانی) رسم کنید، نه فقط میانگین.

## محدودیت‌ها

- این مجموعه فقط ۶ نمونه دارد و برای سنجش آماری کافی نیست. فقط الگو برای توسعه‌ی سنجش است.
- نمونه‌های `natural` را یک مدل نوشته‌اند. قبل از هر ادعای کیفیت باید گویشور بومی بازبینی کند.
- داوری LLM ممکن است به متن خودش امتیاز بیشتری بدهد. برای نتیجه‌ی جدی، بازبین انسانی لازم است.
