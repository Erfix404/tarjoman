## پیکربندی

سرور به‌طور پیش‌فرض روی پورت 8080 گوش می‌دهد. برای تغییرش، متغیر محیطی `PORT` را تنظیم کنید. اگر سرور پشت پراکسی معکوس (reverse proxy) اجرا می‌شود، حتماً `TRUST_PROXY=1` را تنظیم کنید؛ وگرنه IP کلاینت‌ها اشتباه در لاگ ثبت می‌شود.

> **هشدار:** با عوض کردن `SECRET_KEY` همه‌ی نشست‌های فعلی باطل می‌شوند. کاربران از حساب خارج می‌شوند و باید دوباره وارد شوند.

برای اجرای تست‌ها:

```bash
make test
```

اگر تستی با خطای `ConnectionRefusedError` شکست خورد، احتمالاً پایگاه داده هنوز بالا نیامده است. چند ثانیه صبر کنید و دوباره امتحان کنید.

## متن‌های رابط کاربری

- `delete_confirm`: "{count} فایل حذف شود؟ این کار برگشت‌پذیر نیست."
- `setup_done`: "همه‌چیز آماده است!"
- `offline`: "اتصال برقرار نشد. اینترنت را بررسی کنید و دوباره امتحان کنید."
