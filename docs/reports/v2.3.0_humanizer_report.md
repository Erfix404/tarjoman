## 1. New Modules

### `tarjoman/stages/humanizer.py` — PersianHumanizer

Core deliverable implementing:

- **Code & Markdown Table Shielding**: `protect_regions` / `restore_regions` using
  private-use codepoints (U+E000/U+E001) and letter-only index tokens (`_encode_index`).
  Shields fenced code blocks (``` / ~~~), inline code (`...`), and markdown table
  rows (`^[ \t]*\|.*$`) before any transformation, restores byte-identical afterwards.

- **18 AI-Tell Patterns (T1-T18)**:
  - **T1** Copula inflation: می‌باشد/به شمار می‌رود/محسوب می‌شود/به حساب می‌آید/گردیده → natural forms
  - **T2** Ceremonial fillers: لازم به ذکر/شایان ذکر/خاطرنشان/قابل توجه → removed
  - **T3** Significance inflation: اهمیت ویژه/نقش بسزا/جایگاه ویژه → simplified
  - **T4** Generic openers/closers: در دنیای امروز/در عصر دیجیتال/به طور کلی → removed
  - **T5** «در راستای» abuse → برای
  - **T6** Promotional emptiness: بی‌نظیر/فوق‌العاده/مثال‌زدنی/منحصربه‌فرد → stripped
  - **T7** Rule-of-three: detection only (semantic rewrite needed)
  - **T8** Negative parallelism نه تنها...بلکه: detection only
  - **T9** Tacked-on analysis: نشان‌دهنده/بیانگر/حاکی → simplified
  - **T10** Vague authority: detection only
  - **T11** False ranges: detection only
  - **T12** Zero em-dash: —/– → ،
  - **T13** English calques in Persian: در پایان روز→در نهایت / نگاهی بیندازیم→ببینیم
  - **T14** همچنین pileup: detection only
  - **T15** Fake tanvin: گاهاً→گاهی / دوماً→دوم اینکه / ناچاراً→به‌ناچار
  - **T16** Bold-header lists: detection only
  - **T17** Chatbot markers: سؤال بسیار خوبی!/خوشحال می‌شوم/امیدوارم مفید → removed
  - **T18** Universal catch-all: detection only

- **Tanvin Auto-Repair**: 18 Arabic loanwords (لطفا→لطفاً, حتما→حتماً, دقیقا→دقیقاً, etc.)
  with Persian-aware boundaries (`_FA_B_L` / `_FA_B_R`).

- **Fake Tanvin Correction**: 8 Persian words wrongly carrying tanvin
  (گاهاً→گاهی, خواهشاً→خواهش می‌کنم, etc.).

- **`PersianHumanizer.humanize(text, register)`**: Full pipeline —
  shield → de-AI (T1-T17) → tanvin repair → fake tanvin fix → restore.
