# Architecture Decision Records

After TARJOMAN-A0-PROD-3 is owner-frozen, any change that contradicts a locked Architecture Zero decision requires an ADR.

## Naming

`NNNN-short-title.md`

Example:
`0001-change-cache-key-context-policy.md`

## States

- proposed
- accepted
- rejected
- superseded

## Required content

Use `0000-template.md`. An accepted ADR must identify affected Architecture Zero decision IDs and migration/test impact.
