## Required Actions
1. Implement Artifact Store in `src/tarjoman/storage/artifact_store.py`:
   - Target directory structure:
     `<workspace_root>/.tarjoman/artifacts/sha256/<first_2_hex>/<full_sha256>`
     `<workspace_root>/.tarjoman/tmp/` for temporary writes
   - **StoredBlob** (Pydantic model or dataclass):
     - `sha256: str` (64 lowercase hex characters)
     - `size_bytes: int`
     - `path: Path`
     - `mime_type: Optional[str] = None`
     - `created_at: datetime`
     - `metadata: Dict[str, Any]`
   - **ArtifactStore** class:
     - `__init__(workspace_root: Union[str, Path], max_blob_size_bytes: Optional[int] = None)`
     - `store_bytes(data: bytes, mime_type: Optional[str] = None, metadata: Optional[Dict[str, Any]] = None) -> StoredBlob`
     - `store_file(source_path: Union[str, Path], mime_type: Optional[str] = None, metadata: Optional[Dict[str, Any]] = None) -> StoredBlob`
     - `store_stream(stream: BinaryIO, mime_type: Optional[str] = None, expected_sha256: Optional[str] = None, metadata: Optional[Dict[str, Any]] = None) -> StoredBlob`
     - `get(sha256: str) -> Optional[StoredBlob]`
     - `read_bytes(sha256: str) -> bytes`
     - `open_blob(sha256: str) -> BinaryIO`
     - `exists(sha256: str) -> bool`
     - `verify_blob(sha256: str) -> bool`: validates that on-disk file exists, matches expected size, and recomputes SHA-256 to verify byte integrity.
     - `delete_blob(sha256: str) -> bool`: deletes the blob from storage.
     - `collect_garbage(referenced_hashes: Set[str]) -> Tuple[int, int]`: scans storage and removes any unreferenced blobs, returning `(blobs_removed, bytes_freed)`.
     - `list_blobs() -> List[StoredBlob]`

2. Enforce Mandatory Invariants (§25.3, §25.4, D20, D43):
   - **Atomic Writes (§25.4)**:
     - Write to a unique temporary file in `<workspace_root>/.tarjoman/tmp/`.
     - Compute SHA-256 incrementally while streaming/writing.
     - Flush and fsync (where supported).
     - Atomic rename (`os.replace`) into `sha256/<ab>/<full_sha256>`.
     - Interrupted write handling: if an exception occurs (e.g. simulated crash, write error, quota exceeded), temp file is immediately cleaned up and NO partial or completed blob exists in the destination store!
   - **Deduplication by SHA-256 (§25.3)**:
     - If the blob with the identical SHA-256 already exists in storage, the store recognizes it, verifies its size, cleans up the temp file, and returns the existing `StoredBlob` without duplicating bytes or corrupting the existing file.
   - **Path Traversal Escape Guard**:
     - Strict hash validation: input hashes MUST match `^[a-f0-9]{64}$`.
     - Paths are resolved canonically using `.resolve()`. Any hash or filename attempting to escape the store (e.g. `../../etc/passwd`, absolute paths, symlinks pointing outside) MUST be rejected by raising `ArtifactValidationError` or `PolicyViolationError`. Filename cannot escape store!
   - **Retention / Deletion Policy**:
     - Explicit deletion method.
     - Garbage collection based on a set of live referenced hashes.
     - Retention expiration helper or check.

3. Module exports:
   - Create `src/tarjoman/storage/__init__.py` exporting `ArtifactStore`, `StoredBlob`.

4. Comprehensive Tests in `tests/test_artifact_store.py`:
   - **Interrupted Write Tests**:
     - Simulate interrupted write / exception mid-stream; assert temp file cleaned up and no destination artifact exists.
   - **Deduplication Tests**:
     - Store identical content twice; assert same SHA-256, single on-disk file, deduplicated storage.
   - **Filename Cannot Escape Store Tests**:
     - Attempt path traversal (`../../../etc/passwd`, `../secrets.toml`, invalid hashes); assert strict rejection with typed error (`ArtifactValidationError` or `PolicyViolationError`).
   - **Retention / Deletion Tests**:
     - Delete specific blob; assert on-disk file removed.
     - Test garbage collection: store 3 blobs, mark 1 as referenced, collect garbage, assert 2 unreferenced blobs deleted and bytes freed accurately reported.
   - **Integrity & Verification Tests**:
     - `verify_blob()` returns True on valid blob, False or raises on tampered/corrupt blob.
   - All 266 existing tests and all 10 domain benchmarks must pass with zero regressions.
