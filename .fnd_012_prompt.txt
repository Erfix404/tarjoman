2. Implement Architecture Conformance Linter & Checker:
   - Create `src/tarjoman/quality/conformance.py` (and expose via `tarjoman.quality`):
     - `ArchitectureConformanceChecker`:
       - Scans Python source files across `src/tarjoman/` using `ast.parse`.
       - Analyzes all `import` and `import from` statements across packages.
       - Enforces strict boundary rules (§22.1):
         - `RULE_CORE_ISOLATION`: Modules in `tarjoman.core.*` (contracts, errors, config, logging) must NEVER import from `tarjoman.storage`, `tarjoman.providers`, `tarjoman.interfaces`, `tarjoman.audio`, `tarjoman.stages`, `fastapi`, `uvicorn`, `torch`, `whisper`, `faster_whisper`, `comet`, etc.
         - `RULE_INTERFACE_ISOLATION`: Modules in `tarjoman.interfaces.<X>` must NEVER import from `tarjoman.interfaces.<Y>` (e.g. `tarjoman.interfaces.cli` cannot import `tarjoman.interfaces.api` or `mcp`).
         - `RULE_NO_HEAVY_BASE_IMPORTS`: No module in `core`, `quality`, or `storage` may top-level import heavy optional dependencies (`torch`, `whisper`, `faster_whisper`, `comet`, `onnxruntime`, `fastapi`, `uvicorn`).
         - `RULE_DATABASE_INVARIANTS`: SQLite migrations and schema must not declare `BLOB` columns for large files (Invariant D20).
         - `RULE_SECRET_REDACTION`: Checks that error models and loggers enforce redaction and no raw hardcoded API keys exist.
       - Returns a structured report with violated rules, source files, line numbers, and error messages.
       - Method `check() -> List[ArchitectureViolation]` and `enforce() -> None` (raises `ArchitectureViolationError` if any violation is found).

3. Comprehensive Architecture Test Suite in `tests/test_architecture_conformance.py`:
   - **Base Job Installs Without Speech/Eval/Server Extras**:
     - Verify `import tarjoman` executes in under 200ms and does not require or load optional extras (`torch`, `whisper`, `fastapi`, `uvicorn`, `comet`).
     - Test that missing optional modules (simulated via `sys.modules[mod] = None`) do NOT break base importing of `tarjoman.core`, `tarjoman.quality`, `tarjoman.storage`, or `tarjoman.profiles`.
   - **Architecture Violations Fail CI**:
     - Test that the conformance checker successfully passes on current clean codebase.
     - Test that synthetic architecture violations FAIL the checker with detailed diagnostics:
       - Injecting a fake import of `fastapi` or `torch` in `tarjoman.core` triggers `RULE_CORE_ISOLATION`.
       - Injecting cross-interface import (`interfaces.cli` importing `interfaces.api`) triggers `RULE_INTERFACE_ISOLATION`.
       - Injecting a `BLOB` column in SQLite migration triggers `RULE_DATABASE_INVARIANTS`.
   - Test package ownership boundaries per §22.2.

4. Update CI Workflows in `.github/workflows/test.yml`:

     - Sets up clean Python environment.
     - Runs `pip install -e .` (WITHOUT any extras).
     - Verifies base installation imports cleanly.
     - Runs `pytest tests/test_architecture_conformance.py`.
