## Required Actions
1. Migrate the codebase from the flat `tarjoman/` directory into `src/tarjoman/`:
   - `src/tarjoman/__init__.py`
   - `src/tarjoman/cli.py`
   - `src/tarjoman/composers/`
   - `src/tarjoman/core/`
   - `src/tarjoman/domains/`

   - `src/tarjoman/memory/`
   - `src/tarjoman/stages/`

     `src/tarjoman/application/`, `src/tarjoman/providers/`, `src/tarjoman/quality/`, `src/tarjoman/profiles/`, `src/tarjoman/ingest/`, `src/tarjoman/export/`, `src/tarjoman/interfaces/` (including `interfaces/cli/`), `src/tarjoman/audio/`, `src/tarjoman/evals/`, `src/tarjoman/prompts/`.
2. Provide backward compatibility shims or mechanical compatibility:
   - Existing imports like `from tarjoman.cli import cli`, `from tarjoman.stages import ...`, `from tarjoman.core.pipeline import ...`, `from tarjoman.domains.router import ...`, `from tarjoman.composers import ...`, `from tarjoman.memory import ...` MUST continue to work without breaking external consumers or benchmarks.
   - For interfaces/cli, `src/tarjoman/cli.py` can act as the shim pointing to `src/tarjoman/interfaces/cli/` (or vice versa), with a documented deprecation/removal plan comment.
3. Update `pyproject.toml`:
   - Configure setuptools package discovery:
     `[tool.setuptools.packages.find]`
     `where = ["src"]`
     `include = ["tarjoman*"]`
   - Ensure package-data includes registry JSONs:
     `[tool.setuptools.package-data]`
     `"tarjoman.domains" = ["registry/*.json"]`
   - Ensure `project.scripts` correctly points to the CLI entrypoint:
     `tarjoman = "tarjoman.cli:cli"`
4. Invariant: `import tarjoman` MUST remain pure and lightweight:
   - No optional heavy imports (no torch, no whisper, no comet, no fastmcp, no uvicorn) at base import time.
5. Verification:
   - Verify `editable install works`: test in the project venv (`.venv/bin/pip install -e .` or `uv pip install -e .`).
   - Verify `wheel install works in clean venv`: build wheel with `python3 -m build --wheel` and verify installation in a temporary clean virtualenv.
   - Run the full test suite (`.venv/bin/pytest`) and ensure all 96 tests pass.
   - Run the 10-domain benchmark (`.venv/bin/python benchmarks/run_benchmarks.py`) and verify all 10 domains PASS and generate outputs.
