# راهنمای ترجمه‌ی محاوره‌ای (فارسیِ روزمره، ولی خوب)

## در یک نگاه

- **دو سطح:** محاوره‌ی مؤدب («شما»، «می‌دونید») برای مشتری و کاربر اپ؛ خودمانی («تو»، «می‌دونی») برای دوست و شخصیت صمیمی. یکی را انتخاب کن و نگه دار (بخش ۱).
- **فقط چیزی را بشکن که همه می‌شکنند** و همیشه به یک شکل: «می‌خوام»، «می‌شه»، «بذار»، «اونا». نیم‌فاصله در محاوره هم لازم است (بخش ۲).
- **شکستن فعل کافی نیست.** «آیا»، «که»ی ربطی، ضمیر فاعلی و ساختار انگلیسی هم باید بروند: «من نمی‌دانم که او کجا رفته است» ← «نمی‌دونم کجا رفته» (بخش ۲ و ۳).
- **عبارت را با عبارت ترجمه کن:** "No worries!" ← «اشکالی نداره!»، "I miss you" ← «دلم برات تنگ شده» (جدول بخش ۳).
- **سطح را قاطی نکن:** «می‌خواهم برم» غلط است؛ یا «می‌خوام برم» یا «می‌خواهم بروم».
- **کوچه‌بازاری کم و به‌جا** (بخش ۵)؛ قراردادهای چت و پیامک در بخش ۵-۱.


## کی از این سبک استفاده کنیم

- پیام، چت، ایمیل غیررسمی، کامنت و پست شبکه‌های اجتماعی
- رابط کاربری خودمانی (اپ، بازی، ربات)
- زیرنویس و دوبله
- دیالوگ شخصیت‌ها در رمان (روایت رمان معیار می‌ماند؛ راهنمای `literary.md`)
- پاسخ‌های یک دستیار هوشمند به کاربر، وقتی لحن گفت‌وگویی خواسته شده

هدف «فارسیِ نوشتاریِ محاوره‌ای» است: همان‌طور که یک فارسی‌زبانِ باسواد در پیام می‌نویسد. نه زبان اداری است، نه آوانویسیِ لهجه، نه پر از اصطلاح کوچه‌بازاری.

## ۱. دو سطح محاوره

| | محاوره‌ی مؤدب | خودمانی |
|---|---|---|
| مخاطب | مشتری، همکار، کاربر اپ، آدم ناآشنا | دوست، خانواده، مخاطب جوان، شخصیت‌های صمیمی |
| ضمیر | شما | تو |
| فعل | می‌دونید، بفرمایید، بگید | می‌دونی، بیا، بگو |
| نمونه | ممنون که پیام دادید. فردا بهتون خبر می‌دم. | مرسی که پیام دادی. فردا خبرت می‌کنم. |

اگر متن اصلی "you" دارد و معلوم نیست مخاطب کیست، برای محصول و مشتری «شما» و برای گفت‌وگوی دوستانه «تو» بگذار. انتخابت را تا آخر متن نگه دار.

## ۲. املای شکسته: یکدست و خوانا

قانون اصلی: **فقط کلمه‌هایی را بشکن که همه در گفتار می‌شکنند، و همیشه به یک شکل بنویس.**

| معیار | محاوره (همین املا را به کار ببر) | غلط یا نامطلوب |
|---|---|---|
| می‌خواهم | می‌خوام | میخام، میخوام |
| می‌توانم | می‌تونم | میتونم |
| می‌روم / می‌رود | می‌رم / می‌ره | میرم، میره |
| می‌گویم / می‌گوید | می‌گم / می‌گه | میگم |
| می‌دهم | می‌دم | میدم |
| می‌شود | می‌شه | میشه |
| بگذار | بذار | بزار |
| است (پس از صامت) | ـه: خوبه، بده | خوب است (در متن خودمانی) |
| است (پس از مصوت) | ـه یا ـست: چیه، کجاست، اینجاست | |
| هستند / می‌روند | هستن / می‌رن | هستند (در متن خودمانی) |
| آن / آنجا / آن‌ها | اون / اونجا / اونا | |
| خانه / نان / جان | خونه / نون / جون | |
| را | رو (جدا) | کتابو (فقط در دیالوگ خیلی خودمانی) |
| به او / با او / از آن | بهش / باهاش / ازش | |
| چه / چه چیزی | چی | |
| اگر | اگه | |

نکته‌ها:
- **نیم‌فاصله در محاوره هم لازم است:** «می‌خوام»، «نمی‌دونم»، «کتاب‌ها». «میخوام» بی‌دقت به نظر می‌رسد.
- **اسم‌های خاص، اصطلاح‌های فنی و کلمه‌های عربیِ رسمی را نشکن:** «اطلاعات»، «تنظیمات»، «پشتیبانی» همان‌طور می‌مانند.
- **زیادی نشکن:** «داره میاد» درست است، ولی «داره میآد» یا «دارهمیاد» غلط است. لهجه را آوانویسی نکن («میگَم»، «اَصَن»)، مگر شخصیتی که لهجه‌اش مهم است.
- **سطح را عوض نکن:** «من می‌خواهم برم» یعنی نیمی معیار و نیمی محاوره. یا «می‌خوام برم» یا «می‌خواهم بروم».

### نمونه: از جمله‌ی کتابی به محاوره

شکستن فعل‌ها کافی نیست. «آیا»، «که»ی ربطی و ضمیرهای جدا هم باید بروند:

| کتابی یا ترجمه‌ای | محاوره |
|---|---|
| من نمی‌دانم که او کجا رفته است. | نمی‌دونم کجا رفته. |
| به او گفتم که بیاید. | بهش گفتم بیاد. |
| آیا تو می‌آیی یا نه؟ | میای یا نه؟ |
| شاید بتوانیم فردا برویم. | شاید فردا بتونیم بریم. |
| در رابطه با این موضوع، فکر می‌کنم حق با توست. | راجع به این، فکر کنم حق با توئه. |
| او گفت که فردا نمی‌آید. | گفت فردا نمیاد. |
| کتاب من کجاست؟ | کتابم کجاست؟ |
| دارم به خانه برمی‌گردم. | دارم برمی‌گردم خونه. |

## ۳. اشتباه‌های رایج ایجنت‌ها (بد ← خوب)

مشکل اصلی در محاوره، املای شکسته نیست. مشکل این است که **ساختار جمله‌ی انگلیسی** حفظ می‌شود و فقط فعل‌ها شکسته می‌شوند.

## ۴. قاعده‌های جمله‌سازی در محاوره

1. **ضمیر فاعلی را بینداز:** «من فکر می‌کنم که…» ← «فکر کنم…». «تو باید…» ← «باید…».
2. **«که» ربطی را کم کن:** «می‌دونم که میای» ← «می‌دونم میای».
3. **جمله را کوتاه کن:** گفتار، جمله‌ی سه‌خطی ندارد. یک جمله‌ی بلند انگلیسی را به دو یا سه جمله‌ی کوتاه بشکن.
4. **فعل را آخر نگذار، اگر طبیعی نیست:** در محاوره جابه‌جایی رایج است: «رفتم بازار دیروز» ممکن است، ولی زیاده‌روی نکن.
5. **تعارف و «لطفاً»ی ترجمه‌ای را کم کن:** «لطفاً روی دکمه کلیک کنید» در رابط خودمانی ← «روی دکمه بزن».
6. **به جای اسم، فعل بیاور:** «انجام بررسی» ← «بررسی کردن» ← «یه نگاه بنداز».
7. **علامت تعجب را جیره‌بندی کن:** یکی در هر چند پیام کافی است. «!!!» و ایموجی فقط اگر متن اصلی دارد.

---

## ۵. اصطلاح کوچه‌بازاری: کم و به‌جا

«خفن»، «دمت گرم»، «ایول» و «حال کردم» فقط وقتی جا دارند که متن اصلی هم به همان اندازه خودمانی و عامیانه باشد (مثلاً دیالوگ یک نوجوان). برای پیام یک محصول یا دستیار، محاوره‌ی مؤدب کافی است.

---

## ۵-۱. چت و پیامک: علامت‌ها، مخفف‌ها و کش دادن

چت فقط «محاوره» نیست؛ قراردادهای نوشتاری خودش را دارد. آن‌ها را با معادل فارسی‌شان ترجمه کن، نه کلمه به کلمه:

| انگلیسی | معادل فارسی | نکته |
|---|---|---|
| lol / haha | خخخ / 😂 / هههه | «lol» و «لول» را در متن فارسی نگذار |
| lmao / lmfao | خخخخخ / 😂😂 | شدیدتر از lol |
| idk | نمی‌دونم | |
| u / ur / r | تو / ـت / ـی | مخفف انگلیسی در فارسی معادل ندارد؛ کامل بنویس |
| btw | راستی | |
| omg | وای / خدایا | |
| ugh | اَه / اوف | |
| come onnn / pleaseee | بیا دیگهههه / تو رو خدااا | کش دادن را با تکرار حرف آخر فارسی نگه دار، اندازه‌اش مثل اصل |
| it's been forever | خیلی وقته همو ندیدیم | |
| I'm wiped / I'm dead | داغونم / مُردم از خستگی | |
| work was brutal | کار امروز پدرمو درآورد | |
| I'm bailing | جیم می‌شم / می‌زنم بیرون | |
| lame | بی‌مزه / ضایع | |
| deal | قبول / باشه | |

قاعده‌ها:
- **سطح شکستگی را با اصل هماهنگ کن.** پیامی که بی‌نقطه و با حروف کوچک نوشته شده، در فارسی هم بی‌نقطه و شکسته است. ولی نیم‌فاصله را فدا نکن: «می‌دونم»، نه «میدونم» (`tarjoman lint` این را می‌گیرد).
- **ایموجی‌ها همان می‌مانند.** ایموجی اضافه نکن، مگر به‌جای «lol» که در فارسی چت معادلش «😂» یا «خخخ» است.
- **برچسب گوینده** («A:»، «Sarah:») را همان‌طور نگه دار.
- **سلام اضافه نکن.** "hey" اول پیام دوستانه معمولاً در فارسی جا می‌افتد یا «هی» یا «ببین» می‌شود، نه «سلام» که لحن را رسمی‌تر می‌کند.
- **فینگلیش ننویس،** حتی اگر پیام اصلی خیلی خودمانی است. خط فارسی، شکسته.

### نمونه

**متن اصلی:**
> A: come onnn, it's been forever. just come for like an hour
> B: fine but if it's lame I'm bailing lol

**ترجمه‌ی ماشینی:**
> A: بیا دیگه، خیلی وقته. فقط برای حدود یک ساعت بیا
> B: باشه ولی اگه ضایع بود میرم lol

**ترجمه‌ی خوب:**
> A: بیا دیگهههه، خیلی وقته همو ندیدیم. فقط یه ساعت بیا
> B: باشه، ولی اگه بی‌مزه بود جیم می‌شم خخخ

## ۶. نمونه‌ی کامل: پیام یک دستیار

**متن اصلی:**
> Great news! I've finished reviewing your document. Overall, it looks really solid, but there are a few areas where the wording could be tightened up. Would you like me to go ahead and make those changes for you?

**ترجمه‌ی ماشینی:**
> اخبار عالی! من بررسی سند شما را به پایان رساندم. به طور کلی، واقعاً محکم به نظر می‌رسد، اما چند حوزه وجود دارد که در آن‌ها عبارت‌پردازی می‌تواند فشرده‌تر شود. آیا مایلید که من پیش بروم و آن تغییرات را برای شما اعمال کنم؟

**محاوره‌ی مؤدب:**
> خبر خوب! متنتون رو خوندم. در کل خیلی خوبه، فقط چند جاش رو می‌شه کوتاه‌تر و دقیق‌تر نوشت. می‌خواید خودم درستش کنم؟

**خودمانی:**
> خبر خوب! متنت رو خوندم. در کل خیلی خوبه، فقط چند جاش رو می‌شه جمع‌وجورتر نوشت. می‌خوای خودم درستش کنم؟

## ۷. نمونه‌ی کامل: دیالوگ رمان

**متن اصلی:**
> "You're late again," Mom said, not looking up from the stove.
> "I know, I know. The bus broke down. It's not my fault!"

**ترجمه‌ی ماشینی:**
> «تو دوباره دیر کردی»، مامان گفت، بدون اینکه از اجاق گاز بالا را نگاه کند.
> «من می‌دانم، من می‌دانم. اتوبوس خراب شد. این تقصیر من نیست!»

**ترجمه‌ی خوب** (روایت معیار، دیالوگ محاوره‌ای):
> مامان بی‌آنکه سرش را از روی اجاق بلند کند، گفت: «باز که دیر کردی.»
> «می‌دونم، می‌دونم. اتوبوس خراب شد. تقصیر من نیست که!»

## ۸. چک‌لیست پیش از تحویل

- [ ] هیچ فعل معیار («می‌خواهم»، «است») وسط متن محاوره‌ای نمانده؟
- [ ] املای شکسته یکدست است و نیم‌فاصله‌ها درست‌اند؟
- [ ] اگر متن را بلند بخوانی، شبیه حرف زدن یک آدم واقعی است؟
