# فهرست گرته‌برداری‌ها (calque)

گرته‌برداری یعنی ساختار یا اصطلاح انگلیسی کلمه به کلمه به فارسی بیاید. جمله از نظر دستوری غلط نیست، ولی فارسی‌زبان آن را این‌طور نمی‌گوید. این فهرست را وقتی باز کن که لینتر هشدار `calque` داده یا جمله‌ای «ترجمه‌ای» به نظرت می‌رسد. منبع‌های اصلی: «غلط ننویسیم» ابوالحسن نجفی و «نگارش و ویرایش» احمد سمیعی گیلانی.

## در یک نگاه

- **مجهول با «توسط» نه:** اگر کننده معلوم است، جمله را معلوم کن (بخش ۱).
- **اصطلاح را با اصطلاح ترجمه کن:** «نقش بازی کردن»، «نقطه نظر»، «در پایان روز» (بخش ۲).
- **حرف اضافه‌ی انگلیسی را نیاور:** «تأثیر روی» ← «اثر بر»، «در رابطه با» ← «درباره‌ی» (بخش ۳).
- **فعل کمکی زائد نه:** «به عمل آوردن»، «صورت دادن»، «مورد استفاده قرار دادن» (بخش ۳).
- **جمع عربی برای کلمه‌ی فارسی نه:** «پیشنهادات» ← «پیشنهادها» (بخش ۴).
- **ساختار جمله‌ی انگلیسی نه:** «این جالب است که»، «وجود ندارد که»، «آیا شما» (بخش ۵).

---

## ۱. مجهول با «توسط»

فارسی برای مجهولی که کننده‌اش معلوم است، معمولاً جمله‌ی معلوم می‌سازد.

| انگلیسی | گرته | فارسی |
|---|---|---|
| The book was written by Tolstoy. | این کتاب توسط تولستوی نوشته شد. | این کتاب را تولستوی نوشت. |
| The law was ratified by parliament. | قانون توسط مجلس تصویب شد. | مجلس قانون را تصویب کرد. |
| He was killed by the robbers. | او توسط سارقان به قتل رسید. | دزدها او را کشتند. / به دست دزدها کشته شد. |
| The project was completed by our team. | پروژه توسط تیم ما تکمیل شد. | تیم ما پروژه را تمام کرد. |

اگر «by» ابزار است نه کننده، «با» بیاور: «با چاقو کشته شد». اگر کننده مهم نیست، مجهول بی‌کننده درست است: «نمونه‌ها در یخچال نگهداری شدند».

|---|---|---|

## ۳. حرف اضافه و فعل کمکی

| گرته | فارسی |
|---|---|
| تأثیر تحریم‌ها روی اقتصاد | اثر تحریم‌ها بر اقتصاد |
| در رابطه با / در خصوص این موضوع | درباره‌ی این موضوع |
| بازدید به عمل آوردن | بازدید کردن |
| آزمایش صورت دادن | آزمایش کردن |
| مورد استفاده قرار دادن | به کار بردن، استفاده کردن |
| اقدام به ثبت‌نام کنید | ثبت‌نام کنید |
| در اختیار قرار دادن | دادن، فراهم کردن |
| دارای دو فرزند است | دو فرزند دارد |
| مورد نیاز نیست | لازم نیست |

## ۴. جمع عربی برای کلمه‌ی فارسی

| نادرست | درست |
|---|---|
| پیشنهادات | پیشنهادها |
| گزارشات | گزارش‌ها |
| بازرسین | بازرسان |
| گرایشات | گرایش‌ها |
| آزمایشات | آزمایش‌ها |

جمع عربیِ کلمه‌ی عربی («اطلاعات»، «مقالات»، «جزئیات») درست است.

## ۵. ساختار جمله

| انگلیسی | گرته | فارسی |
|---|---|---|
| It is interesting that ... | این جالب است که ... | جالب است که ... |
| It is not from X that ... | این از X نیست که ... | ... را از X انتظار نداریم / X نیست که ... |
| There is no door better than ... | هیچ دری بهتر از ... وجود ندارد که | هیچ دری بهتر از ... نیست |
| Are you sure? | آیا شما مطمئن هستید؟ | مطمئنید؟ |
| You will need to sign in. | شما نیاز خواهید داشت که وارد شوید. | باید وارد شوید. |
| Inflation remains high. | تورم بالا باقی می‌ماند. | تورم همچنان بالاست. |
| in a future release | در یک انتشار آینده | در نسخه‌های بعدی |
| a single man in possession of a good fortune | یک مرد مجرد در مالکیت یک ثروت خوب | مرد مجردِ پولدار |

ساختار گروه اسمی، «یک»، و زنجیره‌ی اضافه: `structural-grammar-rules.md`.
